# Metric families checklist

Names only. Retrieve definitions with `search_docs("metric taxonomy")` and cite them.

- Task: accuracy, task completion rate, exact match, precision, recall, F1
- Quality: relevance, coherence, faithfulness, helpfulness, tone
- Safety: toxicity, PII leakage, jailbreak resistance, policy adherence, refusal behaviour
- Operational: latency, cost per request, token usage, throughput

A complete evaluation reports at least one metric from every family.
