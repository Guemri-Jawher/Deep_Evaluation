# Terminology to use in search queries

Use the guides' own wording; vector and keyword search both reward it.

| User says | Search for |
|-----------|-----------|
| "is my RAG any good" | RAG triad, context relevance, groundedness, answer relevance |
| "retrieval quality" | recall at k, precision at k, MRR, NDCG, hit rate |
| "hallucination" | faithfulness, groundedness, grounding check |
| "judge" | LLM as a judge, rubric, position bias, verbosity bias, Cohen's kappa |
| "agent testing" | trajectory evaluation, tool selection accuracy, pass^k, step efficiency |
| "regression" | eval gate, CI, golden set, baseline |
| "agent loops" | termination budgets, max steps, repeated tool calls |
| "security" | prompt injection, lethal trifecta, least privilege, guardrails |
| "multi agent" | supervisor-worker, orchestrator-workers, handoffs |
